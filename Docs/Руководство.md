# PupSeekRDP — руководство пользователя

RDP-менеджер + инструменты администратора Windows + мониторинг в одном окне.
Версия: 3.9.5. Приложение portable: ставится запуском `PupSeekRDP.exe`,
все данные — в `%PROGRAMDATA%\PupSeekRDP\`.

## 1. Три вкладки главного окна

| Вкладка | Что это |
|---|---|
| **Сессии** | Сайдбар: RDP-сессии, SSH/Web/Telnet-закладки, группы, drag&drop. Центр: встроенные вкладки подключений |
| **Книга** | Адресная книга ПК: группы-пилы, поиск, ПКМ-меню действий, импорт из AD/CSV |
| **Дашборд** | Мониторинг: виды **События** (WMI), **Монитор** (Zabbix-агент/SNMP), **Web** (HTTP-проверки) |

## 2. Подключения (сайдбар «Сессии»)

- **RDP** — встроенный (ActiveX) или внешним `mstsc /v`. Креды: вручную, из KeePass, кэш сессии. Импорт готовых файлов `.rdp` («Сессии → Импорт .rdp…»).
- **Shadow** — подгляд за сессией пользователя (`mstsc /shadow`, с управлением или без).
- **SSH** — встроенный терминал xterm.js (TUI: MC, vim, nano работают). Креды из KeePass; альтернатива — SSH-ключ (ppk/pem/key): путь ключа в карточке сессии, первый выход — подпись `known_hosts` с предупреждением о неизвестном/изменённом ключе. При обрыве связи — авто-переподключение (2/5/15 с, 3 попытки), счётчик и аудит `ssh.reconnect`.
- **Telnet** — встроенный терминал, порт 23 по умолчанию, логин интерактивно (`+ Сессия…` → тип Telnet). Тоже авто-переподключается при обрыве.
- **Web** — встроенный браузер (WebView2) для Grafana/webmin/роутеров.
- **CMD / PowerShell / MMC** — меню «Инструменты»: встроенные консоли и оснастки (`compmgmt`, свои `.msc`).

## 3. Книга: ПКМ-меню компьютера

Подключиться (Shadow/RDP/Web/SSH) · Информация о компьютере · Computer Management ·
Службы · Просмотр событий · События WMI · Диспетчер задач · Отслеживать события/SNMP ·
Домен: ФИО учётки, службы, локальные администраторы, GPO Results, где залогинен,
открытые файлы, реестр, сообщение · Перезагрузить · Пинг/Tracert · Диск C$ ·
Завершить сессию · Группа/Редактировать/Удалить.

## 4. Мониторинг (Дашборд)

- **События** — опрос журналов Windows по WMI (Critical/Error), звук+баллун, «Спросить ИИ» (локальная Ollama).
- **Монитор** — прямой опрос Zabbix-агента (порт 10050): CPU/RAM/диски/сеть/службы, графики, автонастройка агента; fallback на SNMP.
- **Web** — проверки URL (код + время ответа), баллун «Ресурс недоступен».

## 5. Инструменты администратора (отдельные окна)

| Окно | Назначение |
|---|---|
| SFTP-клиент | Две панели (локально/удалённо), обмен из SSH-сессии |
| Удалённый реестр | Разделы и параметры всех типов |
| Диспетчер задач | Процессы по WMI, завершение |
| Инфо / Железо / Софт | WMI-сводки (CPU/RAM/диски, программы), копирование в Excel |
| GPO Results | `gpresult` с удалённого ПК |
| Журнал событий | WMI-чтение Event Log, фильтр по ID |
| Локальные админы | Состав группы + смена пароля локального пользователя |
| Открытые файлы | По всем серверам, «закрыть у всех» |
| Поиск пользователя | Где залогинен (AD + qwinsta) |
| Проверка портов | TCP-сканер хоста: пресеты (Сетевые/Web/БД/Все), параллельно 40, «Стоп» |
| Сниппеты SSH | Команды-шаблоны по группам → отправка в терминал Enter/без Enter |
| Журнал действий | Просмотрщик аудита: все месяцы (+gzip), фильтр по тексту/результату, «В блокноте» |
| Удалённая консоль | Выполнение одной команды на удалённом ПК: WinRM (`Invoke-Command`), фолбэк WMI, кириллица без кракозябр |
| Туннели SSH | Port forwarding: local/remote/dynamic (SOCKS5), порт и адрес назначения, старт/стоп с кредами без сохранения |

## 6. Пароли (KeePass)

Встроенное хранилище `.kdbx` («Инструменты → Пароли»): автоподстановка в RDP,
SSH, Web BasicAuth. Мастер-пароль нигде не сохраняется.

## 7. Туду и календарь

Задачи с напоминаниями, импорт `.ics` по URL (webcal), автосинк, QR-привязка
телефона (диктофон → задачи), мобильное приложение-компаньон.

## 8. Настройки

- **Инструменты → Тема**: Light / Olive.
- **Инструменты → Настройки цвета**: цвета шапки дашборда, хедеров диалогов, области RDP, пил.
- **Инструменты → Журнал действий**: аудит (`audit_ГГГГ-ММ.jsonl`) — подключения, shadow, перезагрузки, logoff, смена паролей, правки книги, туннели, сниппеты, удалённые команды. Пароли в журнал не пишутся никогда. Хранение: ретеншн 12 месяцев, файлы >20 МБ сжимаются в gzip автоматически.
- **Инструменты → Экспорт/Импорт**: книга и сессии (CSV/JSON).
- **Ctrl+K → Палитра команд**: быстрый поиск — действия, инструменты и **открытые сессии** (RDP/SSH/Web/Telnet/встроенные/консоли); Enter выполняет, Esc закрывает.

## 9. Данные и бэкап

Всё — JSON в `%PROGRAMDATA%\PupSeekRDP\` (`addressbook.json`, `custom_sessions.json`,
`rdp_sessions.json`, `todo.json`, `colors.json`, `known_hosts.json`,
`ssh_snippets.json`, `port_forwards.json`, `keepass.json` — только настройки,
сам `.kdbx` отдельно). Для переноса достаточно скопировать папку.
Ежедневный бэкап данных: zip в `%PROGRAMDATA%\PupSeekRDP\backup\`, ротация 7 дней
(в архив попадают все JSON + аудит, расписание запускается при старте).
Исходники: git-репозиторий + bare-бэкап `D:\temp\Clo-backup\cpro.git`, тег на релиз.

## 10. Обновление

Закрыть приложение (трей → Выход) → заменить `PupSeekRDP.exe` → запустить.
История изменений: `RELEASE-NOTES-3.9.5.md`.
