# Pup Seek RDP — описание возможностей

**Текущая версия:** 3.9.5
**Платформа:** Windows 10/11 x64 (.NET 8 self-contained, portable — не требует .NET Runtime)
**Автор:** M.A.D. + Claude (Anthropic)

---

## 1. RDP Manager

- **Встроенный RDP-клиент** (AxHost + MsTscAx ActiveX) и подключение внешним `mstsc /v`.
- **Shadow** — подгляд за сессией пользователя (`mstsc /shadow`, с управлением или без, `/noConsentPrompt`).
- **Креды** в порядке: per-session override → KeePass (`PupSeekRDP/RDP`) → общий кэш/промпт; AutoOpen сессий восстанавливает вкладки при старте.
- **Импорт `.rdp`** — «Сессии → Импорт .rdp…»: host/user/port/full address/gateway и т.д. разбираются из файла, создаются сессии.
- Сайдбар: RDP + SSH/Web/Telnet-закладки, группы-пилы, drag&drop порядок, поиск.
- Три вкладки: **Сессии** (подключения), **Книга** (адресная книга), **Дашборд** (мониторинг).

## 2. SSH / Telnet / Web

- **SSH** — встроенный xterm.js-терминал (MC, vim, nano, less), SFTP-клиент, креды из KeePass.
  - **SSH-ключи**: путь ключа (ppk/pem/key) в карточке сессии; публичная аутентификация поверх `SshAuth.BuildConnectionInfo`.
  - **known_hosts**: первый выход — диалог доверия (подпись отпечатка), неизвестный/изменённый ключ — явное предупреждение (`known_hosts.json`).
  - **Auto-reconnect**: обрыв → 2/5/15 с (3 попытки), счётчик в терминале, аудит `ssh.reconnect`.
- **Telnet** — встроенный терминал (IAC-протокол), авто-переподключение при обрыве, аудит `telnet.reconnect`.
- **Web** — встроенный WebView2-браузер (Grafana/webmin/роутеры), IE11-эмуляция для legacy.
- **Сниппеты SSH** — команды-шаблоны по группам («Сниппеты» в терминале, «Сниппеты SSH…» в инструментах): отправка Enter/без Enter, меню по группам, аудит `ssh.snippet`.

## 3. Туннели SSH (port forwarding)

- **Local** (L), **Remote** (R), **Dynamic** (SOCKS5) — форма «Туннели SSH…» из инструментов и палитры.
- Путь/пароль/ключ не хранятся — креды запрашиваются при каждом запуске.
- Старт/стоп каждого туннеля и всех сразу, состояния, аудит `ssh.tunnel.start/stop`, валидация адреса/порта.

## 4. Консоли и оснастки

- **CMD / PowerShell** — встроенные в шапку (история, Ctrl+C, Ctrl+V, кириллица).
- **Встроенные программы** (`.msc` и свои exe/bat) — «Встроенная программа…», история 20 последних.
- **Удалённая консоль** — выполнение одной команды на удалённом ПК: WinRM (`Invoke-Command -EncodedCommand`), фолбэк WMI (файл через `admin$`); кодировки UTF-8/OEM (CP866) декодируются без кракозябр; аудит `remote.command`.

## 5. Инструменты администратора (ПКМ книги и меню «Инструменты»)

- Информация о компьютере · Computer Management · Службы · Журнал событий · События WMI · Диспетчер задач · GPO Results · Локальные админы · Открытые файлы · Поиск пользователя · Реестр · Диск C$ · Пинг/Tracert · Перезагрузка · Завершение сессии · Смена пароля.
- **Проверка портов** — TCP-сканер: пресеты Сетевые/Web/БД/Все (равные отступы кнопок), параллельность 40, таймаут 1 с/порт, «Стоп», сортировка по порту, зелёный «открыт».
- **SFTP-клиент** — две панели, F5/F6/F7/F8, встроенный редактор в Notepad, поиск.
- **Экспорт/Импорт** книги и сессий (CSV/JSON).

## 6. Аудит, ретеншн, бэкап

- **Журнал действий** — аудит `audit_ГГГГ-ММ.jsonl`: подключения, shadow, перезагрузки, logoff, смена паролей, правки книги, туннели, сниппеты, удалённые команды. Пароли не пишутся никогда.
- **Просмотрщик аудита** — «Журнал действий…»: все месяцы (+gzip), фильтр по тексту и результату, счётчик, «В блокноте».
- **Ретеншн** — хранение 12 месяцев, файлы >20 МБ сжимаются в gzip.
- **Ежедневный бэкап данных** — zip всех JSON + аудита в `%PROGRAMDATA%\PupSeekRDP\backup\`, ротация 7 дней, запуск при старте приложения.

## 7. Палитра команд (Ctrl+K)

- Быстрый поиск: действия, инструменты, настройки и **открытые сессии** (RDP, SSH/Web/Telnet, встроенные программы, консоли CMD/PS) — сессии в начале списка.
- Фильтр: начало строки выше Contains, регистр не важен; Enter — выполнить, Esc — закрыть, стрелки — навигация.
- Оформление в стиле программы: hero-шапка, поле в рамке, футер со счётчиком найденного.

## 8. Дашборд (мониторинг)

- **События** — опрос Event Log через WMI (Critical/Error), баллун+звук, детали, «Спросить ИИ» (локальная Ollama).
- **Монитор** — Zabbix-агент (10050): CPU/RAM/диски/сеть/службы, графики, автонастройка агента, fallback SNMP.
- **Web** — HTTP-проверки URL (код + время ответа), «Ресурс недоступен».
- PHP-панель мониторинга (`monitor/`): авторизация bcrypt, дашборд событий по JSON.

## 9. Пароли (KeePass)

- Встроенное хранилище `.kdbx` (KeePassLib 2.50): автоподстановка в RDP/SSH/Web, мастер-пароль не сохраняется.
- Мастер-пароль в памяти 15 минут, авто-reopen базы после закрытия, автопредложение записи новых учёток.

## 10. Книга адресов

- Группы-пилы, поиск, inline-редактирование, импорт из AD/CSV, экспорт CSV (защита от formula injection), Refresh All (WMI + ping), «Кто залогинен».

## 11. Туду и календарь

- Задачи с напоминаниями, импорт `.ics` (webcal), автосинк, QR-привязка телефона.

## 12. Хранение данных

JSON в `%PROGRAMDATA%\PupSeekRDP\`: `addressbook.json`, `custom_sessions.json`, `rdp_sessions.json`, `todo.json`, `colors.json`, `known_hosts.json`, `ssh_snippets.json`, `port_forwards.json`, `embedded_apps.json`, `keepass.json` (только настройки), `audit_*.jsonl`, `backup\*.zip`.

## 13. Технологии

- C# / .NET 8, WinForms, single-file self-contained publish (~75 МБ).
- AxHost + MsTscAx (RDP) · WebView2 + xterm.js 5.5.0 (SSH/Web) · SSH.NET 2025.0.0 (SSH/SFTP/туннели) · WinRM + WMI (удалённые команды) · KeePassLib 2.50 · System.Management / DirectoryServices · System.Text.Encoding.CodePages (OEM 866).

## 14. Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl+K` | Палитра команд |
| `Ctrl+клик` | Меню сессии (popup) |
| `Enter` | Выполнить выбранное / отправить команду |
| `Esc` | Закрыть окно |
| `F5` / `F6` / `F7` / `F8` | SFTP: копировать / переименовать / создать / удалить |
