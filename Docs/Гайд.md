# PupSeekRDP — гайд для новых пользователей

Пошаговое введение: что за программа, где что лежит, что делает каждая
функция и как всё настроить. Полная версия этого текста встроена в саму
программу (кнопка «?» в главном хедере, пункт «Справка по программе…»
в палитре Ctrl+K). Краткий справочник — в `Руководство.md`, перечень
возможностей — в `FEATURES.md`. Версия: 3.9.5.

## 0. Что это и с чего начать

PupSeekRDP — рабочее место администратора Windows: RDP-подключения,
адресная книга компьютеров, мониторинг и набор инструментов — в одном
окне. Вместо десятка разрозненных консолей (mstsc, MMC, журналы,
мониторинг) — один сайдбар и одна книга.

Программа portable: ставится запуском `PupSeekRDP.exe`, ничего в реестр
не пишет, .NET ставить не надо (self-contained). Все данные лежат в
папке `%PROGRAMDATA%\PupSeekRDP\` — для переноса на другой ПК достаточно
скопировать её.

При первом запуске вы увидите главное окно: слева сайдбар (Сессии,
Книга, Пароли, Инструменты, Дашборд), справа — вкладки подключений.
Отдельных окон почти нет: книга, дашборд, консоли и MMC встраиваются
прямо в главное окно.

Закрытие окна крестиком НЕ завершает программу, а сворачивает её в трей
(иконка рядом с часами) — опросы и напоминания продолжают работать. ПКМ
по иконке трея: «Показать», «Пароли…», «Перезапустить» (лечит зависший
трей), «Выход» (полный выход — только здесь).

Обновление: закрыть программу через «Выход», заменить `PupSeekRDP.exe`,
запустить.

Про права: самой программе права администратора не нужны. Но почти все
действия с удалёнными ПК (WMI-опросы, C$, перезагрузка, настройка
агентов) требуют, чтобы ВАША учётка была администратором на том ПК —
обычно это доменный админ. Нет прав — увидите «Отказано в доступе», это
нормально и лечится правами, а не программой.

## 1. Главное окно: вкладки и сайдбар

Шапка сверху (36px): логотип, название «RDP Менеджер», бейдж
«Подключено», пилы активной сессии (имя и IP — клик переносит к сессии)
и кружок «?» справа — это справка.

Вкладки главной области:

- **Сессии** — живые подключения: RDP, SSH, Web, Telnet, консоли CMD/PS, оснастки MMC.
- **Книга** — адресная книга компьютеров.
- **Дашборд** — мониторинг: виды События / Монитор / Web.

Сайдбар слева (сверху вниз): Книга, модули (например TODO/шня, если
включены в «Инструменты → Модули…»), Пароли (встроенный KeePass),
Инструменты (выпадающее меню ВСЕХ инструментов), Дашборд.

Трей умеет больше, чем кажется: баллуны о критических событиях и
упавших сайтах (клик по баллуну открывает дашборд), Ctrl+клик средней
кнопкой мыши в любом месте — быстрый переключатель активных сессий,
а Ctrl+K открывает палитру команд поверх любого окна.

## 2. Сессии: подключения

**RDP.** Сессии живут в сайдбаре вкладки «Сессии» и раскладываются по
группам. Заголовок группы «ГРУППА (N)» сворачивается кликом (кроме «Без
группы»), строки таскаются мышью между группами (порядок запоминается),
ПКМ по заголовку — переименовать/удалить группу. У строки две строки:
имя и IP; точка справа — зелёная (подключено) или серая. Даблклик —
переподключить сеанс.

Новую сессию добавляют ПКМ по сайдбару, а готовые подключения из Windows
— через «Инструменты → Экспорт/Импорт → Импорт .rdp…» (хост,
пользователь, порт, шлюз разберутся сами). Пароль программа спросит при
подключении. Порядок поиска пароля: свой пароль сессии → KeePass
(группа `PupSeekRDP/RDP`, запись с именем компьютера) → общий
кэш/запрос. Флажок «Автозагрузка» в меню сессии — открывать ли её при
старте программы.

ПКМ по RDP-сессии: «Войти под другой учётной записью», «Перезапустить
сеанс», «Закрыть», «Редактировать запись», «Группа», а также
Shadow-подгляд за сессией пользователя (работает, если пользователь
залогинен — иначе скажет, что сессий нет) и подключение внешним mstsc.

**SSH / Telnet / Web** создаются пунктом «+ Сессия…». SSH — встроенный
терминал: работают MC, vim, nano. Пароль берётся из KeePass или
спрашивается; вместо пароля можно указать SSH-ключ (ppk/pem/key) в
карточке сессии. При ПЕРВОМ подключении программа покажет отпечаток
ключа сервера — сверьте его и только потом подтверждайте
(предупреждение об изменённом ключе потом — повод насторожиться). При
обрыве связи терминал переподключается сам (3 попытки через 2/5/15
секунд, счётчик виден прямо в терминале). В SSH-панели две полезные
кнопки: «Сниппеты» (готовые команды — 509 примеров из коробки, запуск
двойным кликом или Enter) и «SFTP» (обмен файлами, две панели; F5
скачать, F6 закачать, F7 папка, F8 удалить). Web — встроенный браузер
для Grafana, webmin и роутеров (есть Обновить и информация о
соединении). Telnet — порт 23 по умолчанию, логин вводится интерактивно.

**Консоли CMD/PS** («Инструменты») открываются во вкладке, история
команд запоминается, работают Ctrl+C / Ctrl+V. «Встроить ММС» открывает
любую оснастку .msc во вкладке; последние 20 запоминаются в подменю
(крестик удаляет из истории), а кнопка «Добавить MMC» встраивает пустой
mmc.exe (набранные оснастки сохраняются через File → Save).

## 3. Книга: адресная книга

Центр программы: список всех ваших ПК и серверов. Отсюда подключаются,
сюда смотрят мониторинг и инвентаризации. Каждая строка: точка «в сети»
(пинг), точка живой RDP-сессии, группа-бейдж, компьютер, ФИО, логин,
телефон, IP, последний сеанс, коричневая пила новых событий. ФИО и
телефон правятся прямо в таблице. Даблклик — диалог редактирования
(компьютер, ФИО, логин, телефон, IP, группа). Клик по шапке сортирует.

Группы-пилы под шапкой: Все / Пользователи / Сервера / Сетевое / МФУ /
свои / Без группы. На пиле — счётчик записей. Свои группы: ПКМ по ряду
пил → «Создать группу» (там же переименовать и удалить; записи
удалённой группы падают в «Без группы»). Поиск справа в шапке ищет по
всем колонкам сразу.

Рядом с пилами — контекстные кнопки: при «Сервера» — «Открытые файлы»,
при «Пользователи» — «Сообщение всем», при «Все» — «Инвентаризация
SOFT» и «Сводная таблица HARD».

ПКМ по компьютеру — главное меню действий. Подключиться (Shadow —
подгляд за пользователем, RDP), «Добавить в сессии» (вкладка без
коннекта), копирование имени/IP, информация о компьютере, Computer
Management, службы, просмотр событий, события WMI, диспетчер задач.
Подменю ДОМЕН: ФИО учётки, управление службами, локальные администраторы
(+ смена пароля), GPO Results, поиск где залогинен пользователь,
открытые файлы по всем серверам, удалённый реестр, сообщение
пользователю. Дальше: перезагрузка (с подтверждением), пинг, tracert,
диск C$, передача файла, назначение группы, редактировать, удалить.

Мониторинг включается тут же двумя тумблерами: «Отслеживать события»
(вид События в дашборде) и «Отслеживать по SNMP» (вид Монитор без
Zabbix-агента). У отслеживаемых в колонке «Компьютер» подсказка, а новые
события прилетают в коричневую пилу сами.

Футер: «Обновить всё» (пинг + WMI-опрос всех ПК: пользователь, IP,
последний сеанс, ФИО из AD), «Обновить ФИО», «Импорт из AD» (шаг 1 —
пользователи из AD, шаг 2 — компьютеры: пинг + WMI-логин, 15 потоков),
«Прервать» (останавливает долгую операцию), «Удалить», «Закрыть». Слева
в статусе — счётчики и прогресс. Экспорт/импорт CSV — через «Инструменты
→ Экспорт/Импорт» (в экспорте можно выбрать группу и колонки).

## 4. Дашборд: мониторинг

Три вида, переключатель — пилы справа в шапке (колокол/компьютер/
глобус, активный подсвечен).

**СОБЫТИЯ.** Опрос журналов Windows по WMI (уровни Critical/Error) на ПК
с включённым «Отслеживать события». Таблица: время, уровень (красится),
источник, ID, хост, сообщение. Фильтры: уровень (Все/Critical/Error),
период (30 мин / 1 час / 24 часа / 2 дня / свой диапазон), фразы хостов.
Кнопки шапки: Обновить (опросить сейчас), Проверка ИИ (требует локальную
Ollama llama3.2 — без неё покажет гайд по установке), Настройки
(уведомления, интервал, хранение), FTP. ПКМ по событию: «Спросить ИИ»
(расшифровка человеческим языком), «Найти в Google». Даблклик —
карточка деталей (текст добирается с сервера до 5 секунд). Показанные
строки выгружаются в CSV.

**МОНИТОР.** Живые метрики: пинг, CPU %, свободная RAM %, диски,
температура, аптайм, версия агента, кнопка деталей. Сверху — пилы
статистики: Всего / В сети / Ошибки / Внимание / Диски <20% / Службы
стоп / Web OK / возраст опроса (оранжевый, если старше 30 минут).
Источники по порядку: Zabbix-агент на ПК (TCP порт 10050) → fallback
SNMP (UDP 161); пинг — отдельно по ICMP. Строка краснеет и показывает
ERR, если связи нет.
Чтобы данные появились: 1) ПК в мониторинге (кнопка «Добавить запись»:
хост, IP через запятую, метод Агент/SNMP, community/порт/версия — либо
тумблеры книги); 2) для агента — установлен Zabbix Agent, открыт TCP
10050, IP вашего компьютера внесён в Server= конфига агента (кнопка
«Настроить агентов» дописывает сама через WMI — нужны права админа на
ПК); 3) для SNMP — открыт UDP 161, community и версия совпадают
(карточка SNMP в настройках). Колонка IP берётся из книги: без IP опрос
идёт по имени, а имена за VPN часто не резолвятся. Прочерк «—» — датчик
не поддерживается (температуры нет на виртуалках; у SNMP нет температуры
и версии) или истории меньше двух опросов. Кнопка «Детали» открывает
KPI, диски, топ сети, службы (кружки — бегут, квадраты — стоят), I/O
дисков и графики за 2 дня. Все подробности — по кнопке «Помощь в
настройке» в окне настроек дашборда (там же команда проверки
Test-NetConnection).

**WEB.** Проверки сайтов: код ответа и время. URL добавляются кнопкой
«Добавить URL» (название, адрес, таймаут) или ПКМ. В строке: открыть в
браузере, проверить сейчас, вкл/выкл, удалить. В деталях — график
времени ответа (16 баров) и 5 последних проверок. Падение — баллун
«Ресурс недоступен». Настройки вида: интервал (по умолчанию 5 минут),
таймаут, параллельность.

## 5. Инструменты: все окна

Меню «Инструменты» в сайдбаре (дубли — в палитре Ctrl+K):

- CMD / PowerShell — встроенные консоли во вкладке.
- Встроить ММС — оснастки .msc во вкладке + история 20 недавних.
- Экспорт/Импорт — книга в CSV (с выбором группы и колонок), сессии в JSON, импорт .rdp.
- Backup… — полный бэкап в zip по галочкам (12 наборов: сессии, книга, сниппеты, задачи, дашборды, оформление, FTP, модули, KeePass с .kdbx, аудит, MMC, веб-монитор) + автобэкап по расписанию с ротацией; восстановление — из того же окна.
- Сессия / В книгу — новый SSH/Web/Telnet-ярлык / новая запись книги.
- Проверка портов… — TCP-сканер хоста: пресеты (Сетевые/Web/БД/Все/1С/Mail), диапазоны вида 80-82 и 100+, 40 потоков, кнопка «Стоп», сортировка по порту, открытый — зелёным.
- Управление сниппетами… — редактор команд-шаблонов (имя/группа/команда/пояснение); запуск — из пикера в SSH-панели двойным кликом или Enter, каждый запуск пишется в аудит.
- Удалённый терминал… — выполнить одну команду на удалённом ПК: WinRM, при недоступности — фолбэк WMI; кириллица без кракозябр; Ctrl+Enter — выполнить из многострочного поля; аудит remote.command.
- Туннели… — SSH port forwarding: local/remote/dynamic (SOCKS5); логин/пароль/ключ каждый раз спрашиваются и нигде не хранятся; старт/стоп по одному и всех сразу.
- Палитра команд — быстрый поиск всего.
- Модули… — встраиваемые модули (TODO и будущие): вкл/выкл без потери данных.
- Сменить пароль — сбросить общий кэш RDP-пароля (лечит «Недопустимые учётные данные» после опечатки).
- Тема — светлая / оливковая (перезапустит программу).
- Настройки цвета… — цвета шапки дашборда, хедеров окон, области RDP, пил книги; «Сохранить гамму» запоминает набор под каждую тему, «Сбросить» откатывает.
- Журнал действий… — просмотр аудита: все месяцы (включая сжатые), фильтр по тексту и результату, счётчик, «В блокноте».

Из книги и дашборда открываются: инвентаризации HARD/SOFT (железо по
WMI и программы — обе с кнопками помощи и готовыми скриптами), открытые
файлы (по всем серверам, «закрыть у всех»), локальные админы (+ смена
пароля), GPO Results, удалённый реестр, диспетчер задач, журнал событий,
передача файлов.

## 6. Пароли (KeePass)

Кнопка «Пароли» в сайдбаре — встроенное хранилище .kdbx (группы и
записи, создание/правка/удаление, копирование логина/пароля).
Открывается по мастер-паролю (и/или ключ-файлу); мастер-пароль нигде не
сохраняется и держится в памяти 15 минут, потом базу надо открыть
заново. Путь к .kdbx и ключ-файлу запоминаются, сам пароль — никогда.

Автоподстановка: RDP (группа PupSeekRDP/RDP, запись с ИМЕНЕМ компьютера
— пароль подставится сам при подключении), SSH и Web BasicAuth,
FTP-выгрузка (запись PupSeekRDP/FTP). Новых учёток программа сама
предлагает сохранить (спрашивает один раз). Окно паролей немодальное:
его можно держать открытым и копировать оттуда, пока работаете.

## 7. Палитра команд (Ctrl+K)

Главная привычка: Ctrl+K работает из любого окна (глобальный хук).
Начните вводить — найдутся: открытые сессии (всегда первыми), действия и
инструменты, записи книги, TODO-задачи, сниппеты, события и хосты
мониторинга, недавние MMC. Совпадение с начала строки выше обычного,
регистр не важен. Enter — выполнить, Esc — закрыть, стрелки вверх/вниз —
выбор (фокус сразу в списке). Пустой запрос показывает только открытое и
каталог — остальное прячется до первой буквы.

Кнопка «Настройка…» в шапке палитры — окно с галочками: какие строки
каталога видны (выбор запоминается). Там же кнопки «Выбрать все» /
«Снять все».

## 8. ТУДУ и календарь

Модуль задач по умолчанию ВЫКЛЮЧЕН: «Инструменты → Модули…» → включить
TODO — в сайдбаре появится TODO/шня. Внутри: таблица задач,
фильтры-пилы, поиск, диалог задачи (текст, срок, повторы, напоминание).
О сроке напомнит баллун из трея.

Календарь: кнопка импорта внутри окна задач — файл .ics или URL (webcal)
с предпросмотром; автосинхронизация каждые N минут подтягивает события в
задачи. Есть QR-привязка телефона (диктофон → задачи) и
приложение-компаньон.

## 9. Настройки и оформление

- Темы: «Инструменты → Тема» переключает Light/Olive и перезапускает программу (так палитра применяется чисто).
- Цвета: «Инструменты → Настройки цвета…» — шапка дашборда, хедеры всплывающих окон, область шапки RDP, активные пилы книги (текст подбирается сам под фон). Каждая строка: образец, «Изменить…», «Сбросить». «Сохранить гамму» запоминает весь набор под текущую тему.
- Настройки дашбордов — кнопки «Настройки» в шапке каждого вида: События (уведомления, интервал, хранение), Монитор (опрос, таймауты, потоки, пороги, SNMP, уведомления, путь агента), Web (интервал, таймаут, параллельность).
- Размеры окон, ширины и порядок колонок, история консолей CMD/PS — запоминаются сами, настраивать не надо.

## 10. Данные, бэкап, перенос

Всё лежит в `%PROGRAMDATA%\PupSeekRDP\` в виде JSON (открываются
блокнотом): addressbook.json — книга; rdp_sessions.json и
custom_sessions.json — сессии; todo.json — задачи; ssh_snippets.json —
сниппеты; zabbix_agent_settings.json, dashboard_settings.json,
webmon_settings.json — настройки дашбордов; *_history.json — истории
опросов; audit_ГГГГ-ММ.jsonl — журнал действий (паролей там нет
никогда); backup\*.zip — ежедневные бэкапы с ротацией 7 дней.

«Инструменты → Backup…» — полный бэкап в указанный zip по галочкам +
автобэкап по расписанию (ежедневно/еженедельно, ротация, пароль на
архив). Восстановление — из того же окна, со страховкой. Дополнительно
старые аудиты (>20 МБ) сжимаются в gzip, хранение — 12 месяцев.

Перенос на другой ПК: скопировать папку `%PROGRAMDATA%\PupSeekRDP\`
целиком. Для диагноза есть debug.log в той же папке.

## 11. Типовые сценарии

1. Добавить парк: Книга → «Импорт из AD» (подтянет пользователей и компьютеры; шаг 2 сходит по WMI за логинами) или вручную «В книгу». Разложить по группам (свои — ПКМ по пилам), заполнить ФИО/телефоны (можно «Обновить ФИО» из AD).
2. Подключаться без паролей: Пароли → создать .kdbx → группа PupSeekRDP/RDP → записи с именами ПК → подключайтесь, пароль подставится.
3. Видеть события: на нужных ПК включить «Отслеживать события» → Дашборд → События → «Обновить».
4. Видеть железо: поставить Zabbix-агента (кнопка «Настроить агентов» пропишет Server= сама) или включить SNMP → Дашборд → Монитор → «Обновить». Не пошло — кнопка помощи в настройках вида.
5. Учесть софт: Книга → «Инвентаризация SOFT» → «Помощь в настройке» → сохранить GPO-скрипт, развернуть через автозагрузку, подождать перезагрузок → «Сканировать».
6. Учесть железо: Книга → «Сводная таблица HARD» → «Сканировать» (нужны права админа на ПК); при проблемах — «Помощь в настройке» со скриптом подготовки.

## 12. Горячие клавиши

- Ctrl+K — палитра команд (из любого окна).
- Стрелки вверх/вниз — выбор в палитре; Enter — выполнить; Esc — закрыть окно/палитру.
- Ctrl+клик по сессии (и Ctrl+клик средней кнопкой в любом месте) — меню сессии / переключатель активных сессий.
- F5 / F6 / F7 / F8 — SFTP: скачать / закачать-переименовать / создать папку / удалить; Ctrl+V в левой панели SFTP — вставить (скачать).
- Ctrl+Enter — выполнить в многострочном поле (где Enter — новая строка).
- Ctrl+C — прервать/копировать (терминалы, консоли); Ctrl+V — вставить; Ctrl+D — конец ввода в SSH; Пробел/Enter на тумблере — переключить.

## 13. Если что-то не работает

- Требует пароль RDP — проверьте запись в KeePass: ТОЧНОЕ имя ПК, группа PupSeekRDP/RDP, база разблокирована (мастер-пароль живёт 15 минут), в записи не пустой пароль. Что именно не нашлось — видно в debug.log по строке «RDP creds for …».
- Красные строки в Мониторе — ПК недоступен, закрыт порт 10050/161, не прописан Server= агента, чужой community SNMP. Лечится сетью, а не кнопками.
- Пустая таблица SOFT — не развёрнут GPO-скрипт и нет файлов на шаре (кнопка помощи в окне SOFT ведёт за руку).
- Пустая таблица HARD — нет прав администратора/WMI на ПК (кнопка помощи в окне HARD + скрипт подготовки).
- Подозрительно тихо — смотрите %PROGRAMDATA%\PupSeekRDP\debug.log и «Инструменты → Журнал действий…».
- Глючит интерфейс — «Выход» из трея и запуск заново; висящий трей лечит пункт трея «Перезапустить».

## 14. Меню Инструменты — каждый пункт

- CMD — встроенная консоль во вкладке. Пример: ping srv1 -t; история запоминается.
- PowerShell (PS) — пример: `Get-Service | Where-Object {$_.Status -eq 'Running'}`.
- Встроить ММС — оснастка во вкладке. Пример: compmgmt.msc на SRV-1C. Последние 20 — в подменю, «Добавить MMC» — пустая консоль (File → Save сохраняет).
- Экспорт/Импорт — книга в CSV (группа+колонки, например список ПК бухгалтерии), сессии в JSON, импорт CSV (дедуп, отчёт), импорт .rdp (host/user/port/gateway).
- Backup… — 12 наборов (сессии и группы, книга, сниппеты, задачи, дашборды, оформление, FTP, модули, KeePass с .kdbx, аудит, MMC, веб-монитор) + расписание, ротация, пароль. Пример: бэкап перед переустановкой.
- Сессия — ярлык SSH/Web/Telnet. Примеры: SSH root@192.168.1.1; Web https://grafana.local; Telnet на коммутатор.
- В книгу — новая запись. Пример: SRV-DB-01, 192.168.1.10, группа Сервера.
- Проверка портов… — пресет («1С») или диапазон 1540-1541, 40 потоков. Пример: не коннектится 1С — проверить 1540.
- Управление сниппетами… — редактор (имя/группа/команда/пояснение). Пример: df -h в «Диски»; запуск из SSH Enter.
- Удалённый терминал… — одна команда (WinRM, фолбэк WMI), хосты из книги. Примеры: ipconfig /all; Ctrl+Enter из многострочного.
- Туннели… — local (RDP через бастион localhost:13389 → srv:3389), remote, SOCKS5. Креды не хранятся.
- Палитра команд, Модули… (пример: включить TODO), Сменить пароль (лечит «Недопустимые учётные данные»), Тема, Настройки цвета… (пример: корпоративный синий шапки + «Сохранить гамму»), Журнал действий… (пример: фильтр «host.restart» — кто перезагружал ночью).

## 15. Книга: ПКМ — каждый пункт

- ПОДКЛЮЧИТЬСЯ (SHADOW) — подгляд. Пример: «всё пропало» у бухгалтера.
- ПОДКЛЮЧИТЬСЯ (RDP), Добавить в сессии, Скопировать имя/IP (пример: IP для провайдера).
- Информация о компьютере — WMI-таблица в Excel.
- Computer Management / Службы / Просмотр событий на хост (пример: services.msc на SRV-1C).
- События (WMI) — фильтр по EventID (пример: все 4625 за сутки).
- Диспетчер задач — пример: убить зависший 1cv8.
- Отслеживать события / по SNMP — тумблеры мониторинга.
- ДОМЕН → ФИО учётки (пример: чьё sAM «ivanov»); Локальные администраторы (+ смена пароля); GPO Results (пример: почему не встал принтер); Где залогинен (пример: найти уволенного); Открытые файлы (пример: «1Cv8.cdn занят»); Удалённый реестр (пример: HKLM\SOFTWARE\1C); Отправить сообщение (пример: «перезагрузка в 18:00»).
- Перезагрузить (с подтверждением), Пинг/Tracert (пример: где рвётся до филиала), диск C$ (пример: закинуть драйвер), Передать файл (пример: дистрибутив на 10 ПК), Назначить группу / Редактировать / Удалить.

## 16. Сайдбар: меню сессии

Порядок: SHADOW, «Войти под другой учётной записью» (пример: зайти админом), «Автозагрузка» Да/Нет, RDP, копирование/инфо/оснастки/ДОМЕН (те же, раздел 15), «Группа», «Перезапустить сеанс» (пример: зависший RDP), «Редактировать запись» (переименовать/поправить IP/группу), «Закрыть», «+ Сессия».

SSH/Web/Telnet: Открыть; Web — Обновить и инфо; SSH — перезапуск, другая учётка, SFTP; Telnet — перезапуск; переименовать, группа, удалить.

ПКМ по заголовку группы: переименовать, удалить (сессии — в «Без группы»). Заголовок сворачивается кликом, строки таскаются мышью.

## 17. Шапка, трей, пилы

Шапка: логотип, «RDP Менеджер», «Подключено», пилы сессии (клик — перейти), «?» (справка).

Трей: Показать, модули, Пароли, Перезапустить (лечит висящий трей), Выход. Баллуны (клик — дашборд). Ctrl+средний клик — переключатель сессий.
