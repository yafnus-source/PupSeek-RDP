## Зачем

Администратор Windows-сети живёт в десятке окон: `mstsc`, `qwinsta`, `mmc`,
Putty, WinSCP, блокнот с адресами, Excel с инвентарём, просмотрщик событий.
PupSeekRDP собирает всё это в одно окно с вкладками, адресной книгой и
поиском — и добавляет то, чего в отдельных утилитах нет: теневой доступ
в два клика, живые статусы машин прямо в книге, события всего парка на
одном дашборде.

Работает и на одной машине, и на парке в сотни ПК с Active Directory.
Portable, без установки и админских прав, данные — в одной папке.

## Возможности

**Ядро — бесплатно, навсегда:**

- **RDP-менеджер** — вкладки в одном окне, автологон, смена пароля на месте.
- **Теневой доступ** — подключение к чужой сессии в два клика: `shadow`,
  `/control`, `/noConsent`, без ручного ввода `mstsc /shadow`.
- **Адресная книга** — группы и папки, поиск, живые статусы (фоновый пинг,
  цветные точки), импорт из AD и CSV, ФИО/логин/IP прямо в таблице.
- **SSH-терминал** — xterm.js с поддержкой TUI-приложений; **SFTP** —
  двухпанельный менеджер, F5–F8.
- **Консоли** — свой CMD/PowerShell (105 подсказок), MMC-снапины, сниппеты.
- **KeePass** — своя база паролей внутри программы.
- **Инструменты** — порты, туннели, бэкап и перенос данных, аудит действий,
  темы (Light/Olive) и палитра, встроенная справка «?» по каждой функции.

**Платные модули (4.x) — разовый платёж, без подписок:**

## Установка

- **Portable:** скачать `PupSeekRDP.exe` из
  [Releases](https://github.com/yafnus-source/PupSeek-RDP/releases/latest) —
  single-file, .NET устанавливать не нужно.
- **Установщик:** `PupSeekRDP-4.0.0-Setup.exe` (Inno Setup, per-user,
  без прав администратора).
- Данные лежат в `%PROGRAMDATA%\PupSeekRDP\` — перенос на другую машину
  это копирование одной папки. Закрытие окна сворачивает в трей;
  полный выход — ПКМ по трею → «Выход».

## Сборка из исходников

Нужен .NET 8 SDK (Windows):

```
dotnet build ShadowRDP.csproj -c Release
dotnet publish ShadowRDP.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

Прогон тестов (харнесс живёт вне репозитория, рядом с прод-сборками):

```
dotnet build <prod>\source\Harness\Harness.csproj -c Release
<prod>\source\Harness\bin\Release\net8.0-windows\Harness.exe
```
