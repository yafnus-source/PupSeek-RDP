# PupSeekRDP

Рабочее место администратора Windows: RDP-подключения, адресная книга
компьютеров, мониторинг (события / Zabbix / Web), инвентаризации и набор
инструментов — в одном окне. C# / .NET 8, WinForms, portable.

## Установка

- Portable: запустить `PupSeekRDP.exe` (single-file, .NET не нужен).
- Установщик: `PupSeekRDP-<версия>-Setup.exe` (Inno Setup).
- Данные лежат в `%PROGRAMDATA%\PupSeekRDP\` — для переноса достаточно
  скопировать папку. Закрытие окна сворачивает в трей; полный выход —
  ПКМ по трею → «Выход».

## Версии

- **Ядро бесплатно навсегда:** сессии, книга, KeePass, консоли/MMC,
  сниппеты, порты, терминал, туннели, бэкап, аудит, темы, справка.
- **Платные модули (4.x):** События, Монитор, Web-мониторинг,
  инвентаризации HARD/SOFT, TODO, FTP-выгрузка, ИИ-расшифровка,
  доменные инструменты. Пробный период — 10 дней на всё, дальше ключ
  («Инструменты → Лицензия…»).

## Сборка из исходников

Нужен .NET 8 SDK (Windows):

```
dotnet build ShadowRDP.csproj -c Release
dotnet publish ShadowRDP.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

Прогон тестов (харнесс живёт вне репозитория, рядом с прод-сборками):

```
dotnet build <prod>\source\Harness\Harness.csproj -c Release
<prod>\source\Harness\bin\Release\net8.0-windows\Harness.exe
```
